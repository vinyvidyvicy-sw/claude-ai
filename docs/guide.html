Network Automation Portal

Local setup guide: MacBook, Windows laptop, and sharing the code with other engineers

What you are running. A web portal for engineers to start predefined configuration workflows (Cisco ISE, SDA, ACI, NX-OS, Catalyst, Splunk ES, ESXi). It opens in your browser at http://localhost:8000. The portal is in dry-run mode: confirmed workflows are simulated and no device is contacted. All sample workflows are ASSUMPTION samples.

Part 1. Run on a MacBook

1Open Terminal. Press Cmd+Space, type "Terminal", press Enter.
2Check Python. 
python3 --version
If it shows 3.11 or higher, go to step 4. Otherwise install Python (step 3).
3Install Python. Easiest: Homebrew. 
brew --version          # if this fails, install Homebrew from https://brew.sh first
brew install python
python3 --version
No Homebrew? Download the macOS installer (.pkg) from https://www.python.org/downloads/macos/ and click through it. Then open a new Terminal window.
On a Mac use python3 and pip3. Inside the virtual environment (step 5) plain python and pip also work.
4Download the code. 
git clone https://github.com/vinyvidyvicy-sw/claude-ai.git
cd claude-ai
git checkout ccr-5a472752-cizl40
If macOS offers to install the Command Line Tools (for git), accept, wait, then repeat. If asked to sign in to GitHub, see Part 3.
5Create an isolated environment and install. 
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements-dev.txt
Your prompt now starts with (.venv).
6Allow sign-in over plain http (local testing only). 
export PORTAL_COOKIE_SECURE=false
7Create your admin user. 
python -m app.cli create-admin admin
Type a password of at least 12 characters, then repeat it. Nothing shows while you type.
8Start the portal. 
python -m uvicorn app.main:app_factory --factory --port 8000
Leave this window open. Stop with Ctrl+C.
9Open the portal. Go to http://localhost:8000 and sign in as admin.

Coming back later (Mac)

cd claude-ai
source .venv/bin/activate
export PORTAL_COOKIE_SECURE=false
python -m uvicorn app.main:app_factory --factory --port 8000

Updating to the latest version (Mac)

Stop the portal (Ctrl+C), then:

cd claude-ai
git checkout ccr-5a472752-cizl40
git pull
source .venv/bin/activate
pip install -r requirements.txt
export PORTAL_COOKIE_SECURE=false
python -m uvicorn app.main:app_factory --factory --port 8000

Hard-refresh the browser with Cmd+Shift+R. Your users and audit log are kept in data/portal.db.

Part 3. Copy from GitHub to a laptop so other engineers can use it

Two different goals.
(a) Each engineer runs their own copy on their laptop (this guide). Each copy has its own users and audit log.
(b) One shared portal that all engineers open in a browser. That needs one server and HTTPS (see docker-compose.https.yml and the README). Use (b) when you need one central audit log.

A. Give the engineer access to the repository

  1. The engineer needs a GitHub account.
  2. The repository owner opens the repo on GitHub, then Settings, Collaborators (or Manage access), then Add people, and invites the engineer. The engineer accepts the invitation email.
  3. If the repo is private and the engineer has no access, git clone fails with "not found" or "authentication failed".

B. Copy the code to the engineer's laptop

git clone https://github.com/vinyvidyvicy-sw/claude-ai.git
cd claude-ai
git checkout ccr-5a472752-cizl40

Signing in to GitHub from the command line. GitHub does not accept your account password for git. When prompted, either let the browser sign-in window complete (Git Credential Manager, included with Git for Windows and Homebrew git), or use a personal access token as the password: GitHub, Settings, Developer settings, Personal access tokens, create one with read access to the repository. Never share tokens in chat or email.

C. Then follow Part 1 (Mac) or Part 2 (Windows) from the "create environment" step

Each engineer creates their own admin with python -m app.cli create-admin <name>. Local copies do not share users with one another.

D. If git is not allowed on the laptop (zip download)

  1. Open https://github.com/vinyvidyvicy-sw/claude-ai/tree/ccr-5a472752-cizl40 in a browser while signed in.
  2. Click the green Code button, then Download ZIP.
  3. Unzip it, open Terminal or PowerShell in the unzipped folder, and continue from the "create environment" step in Part 1 or Part 2. Updating later means downloading a new zip; copy your data/portal.db into the new folder to keep users and audit history.

E. Moving the code with no internet access to GitHub

On a machine that has the code: git bundle create portal.bundle --all, copy portal.bundle (USB or file share) to the target laptop, then git clone portal.bundle claude-ai and git checkout ccr-5a472752-cizl40. Python packages also need an internet or internal package mirror for pip install.

F. Good practice for sharing

  • The work is on branch ccr-5a472752-cizl40 and is not yet merged into the main branch. Once the team agrees, merge it (pull request) so engineers can clone the default branch without git checkout.
  • Do not commit device credentials, .env, config/inventory.yaml or data/. They are already git-ignored.
  • Copy config/inventory.example.yaml to config/inventory.yaml and edit it with your real devices (config only, never in code).
  • Device credentials are supplied by environment variables, for example PORTAL_CRED_ISE_LAB_USERNAME and PORTAL_CRED_ISE_LAB_PASSWORD, never typed into the portal.
  • To get new versions, each engineer runs git pull and restarts the portal.

Troubleshooting

ProblemFix
python3 / python not found or too oldInstall Python 3.11+ (Mac Part 1 step 3; Windows Part 2 step 1, tick "Add to PATH"). Open a new Terminal/PowerShell window.
git: command not foundMac: accept the Command Line Tools prompt. Windows: install Git from git-scm.com.
Clone says "not found" or "authentication failed"You do not have repository access, or you used your password instead of a token / browser sign-in. See Part 3, A and B.
PowerShell: scripts are disabledSet-ExecutionPolicy -Scope CurrentUser RemoteSigned
Port already in useUse --port 8001 and open http://localhost:8001.
Sign-in seems to do nothingYou skipped the PORTAL_COOKIE_SECURE=false step in this window. Set it again and restart.
Account lockedFive wrong passwords lock it for 15 minutes. Wait, or create another admin: python -m app.cli create-admin admin2.
git pull refuses because of local changesRun git status to see them; do not discard them without checking. Ask the team for help.
Logos missingCheck app/static/img has logo-mii.png and logo-metrodata.png, then restart the portal and hard-refresh the browser.

Quick test checklist

  1. Sign in as admin. The dashboard shows 7 platform tiles and both logos.
  2. Open Cisco NX-OS switches, Create VLAN, choose nxos-lab-1, VLAN 100, name users, click Preview changes.
  3. Click Confirm (simulate) and watch the log. No device is contacted.
  4. Users menu: create an engineer. Copy the one-time temporary password (shown once).
  5. Audit log menu: every action is recorded, with no passwords.
  6. Optional: python -m pytest should show 26 passed.
